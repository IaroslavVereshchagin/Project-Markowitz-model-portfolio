Разбор проекта(русский язык):

В этом проекте мы создаем программу для умного управления инвестициями, используя Модель Марковича и среду разработки - Python.
Конкретный разбор того, что будем делать:
1. В начале подключаемся к официальным серверам Московской Биржи(MOEX) через интернет.
2. Скачиваем реальные исторические цены акций крупнейших команий(Сбербанк, Газпром, Лукойл).
3. Переводим цены в проценты доходности и рассчитываем риски акций *(матрицу ковариации).
4. Используя Модель Марковича, симулируем 5000 случайных портфелей.
5. Находим два самых лучших варианта: портфель минимальным риском и портфель с максимальной эффективностью.

* Матрица ковариации - таблица рисков, которая показывает, как акции колеблются и двигаются в цене относительно друг друга
